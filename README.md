## 🚀 Overview

**WiseTrek** takes the friction out of travel planning. Instead of juggling ten different tabs for itineraries, weather, and local happenings, WiseTrek unifies them. Users can search any destination to instantly discover curated local events, check real-time weather forecasts, and generate custom itineraries using either manual controls or an integrated AI planner. 

Built with a focus on a sleek, minimal, and highly responsive user interface.

## ✨ Features

- **🤖 AI & Manual Planning Modes:** Choose between granular, manual itinerary building or let the AI instantly generate a tailored travel plan.
- **🎫 Event Discovery:** Automatically fetches and categorizes local events (Music, Sports, Food, Culture) based on destination and travel dates.
- **🌤️ Real-Time Weather Integration:** Integrated live weather forecasting to ensure your plans match the climate.
- **🔐 Secure Authentication:** Robust OAuth and JWT-based auth flow protecting private routes and user data.
- **💅 Premium UI/UX:** Glassmorphic elements, smooth route transitions, custom typography (Nunito), and polished interaction states powered by Tailwind v4 and MUI.

## 🛠️ Tech Stack

**Frontend:**
- React (Vite)
- Tailwind CSS v4
- Material UI (MUI)
- React Router DOM
- Lucide React (Icons)

**Backend:**
- Node.js & Express
- MongoDB & Mongoose
- JSON Web Tokens (JWT) / OAuth
